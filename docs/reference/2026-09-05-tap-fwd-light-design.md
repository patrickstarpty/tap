# TAP 浅色视觉规范

创建：2026-09-05。适用：TAP 全平台、Tapper 智能工作区及后续平台实现。用户确认参考富卫 FWD，采用 Codex / Manus 式清晰、简约、浅色的操作体验。此处是 TAP 的应用规范，不声称是 FWD 官方设计系统。

## 品牌与视觉方向

TAP 为平台；Tapper 为智能工作区与 AI Agent 入口，沿用已有 mark/wordmark。FWD 的橙色与暖白作为视觉参考，不替换 TAP 品牌、不使用 FWD Logo。使用[富卫官方品牌材料](https://www.fwd.com/en/playmyway/)作为参考来源。

## 语义色与字型

| 角色      | 值                    | 用途                               |
| --------- | --------------------- | ---------------------------------- |
| 画布      | `#faf9f6`             | 全局底色                           |
| 内容面    | `#ffffff`             | 对话、表格、抽屉、表单             |
| 柔和底色  | `#f3f2ee`             | 导航、悬停、次级区域               |
| 主文字    | `#232b2b`             | 深灰带轻微绿调                     |
| 次级文字  | `#626b68`             | 注释、时间与说明                   |
| 分隔线    | `#e4e6e1`             | 低对比结构分隔                     |
| 品牌橙    | `#e87722`             | 主操作背景与品牌细节，搭配深墨文字 |
| 强调文字  | `#a9470b`             | 浅底链接、选中标签与焦点           |
| 强调浅底  | `#fff1e5`             | 选中与来源引用                     |
| 成功/错误 | `#23745c` / `#b33e38` | 状态独立，配文字/图标              |

采用现有系统无衬线字体栈（含中文回退）；去除工作区标题的 Georgia 衬线。正文 14px、辅助内容 12–13px、工作区标题 26–32px、对话欢迎标题桌面 30–44px / 窄屏 28–32px。代码、ID 与数字按实际内容使用等宽字体/等宽数字，不能用装饰性等宽标题制造科技感。

## 布局与组件

- 保留一级产品 Rail、Tapper 二级 Sidebar 和内容面；聊天输入与答案是主视觉，来源面板按当前机制展开/收起。
- 内容面留白、轻分隔、紧凑工具栏；操作控件 8–10px 圆角，主要内容/浮层 12–16px。浮层才使用柔和阴影，常驻区域通过底色和细线区分。
- 橙色用于主要动作、当前选择、可交互的证据；正常文字不大面积着色。每个工作面保持清楚的主操作。
- 图谱保持多种语义节点颜色与可读标签，画布浅色；BDD、代码、执行日志和模拟设备预览保持浅色，状态不可仅由颜色表达。
- 不增加装饰性渐变、发光、噪点、网格背景、营销文案或无业务作用的数据。

## 交互与验收

所有现有能力、双语、模型选择、上下文、会话恢复、筛选、对话框、资产链接和模拟运行保持。保留 Simulated/Validation 边界；设计变更不引入接口、模型调用或数据重建。

焦点清晰，正文对比度目标至少 4.5:1；橙色底使用深色文字，浅底强调文字采用深橙。悬停/选中/禁用/加载/错误均可辨认；界面原有面板过渡约 160–200ms，尊重 `prefers-reduced-motion`。来源面板在 1100px 以下使用抽屉，Tapper 导航在 640px 以下使用抽屉，页面不得横向溢出。

验收覆盖桌面 1440px、移动 390px、缩减动效、40 张客户截图及原型工作区。保留现有业务测试并运行 Web check；视觉确认与真实后端平台门禁分别记录。最终 token 与组件规则同步到 `apps/web/DESIGN.md`。
