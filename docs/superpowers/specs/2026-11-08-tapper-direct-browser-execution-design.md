# Tapper 直接浏览器执行设计

日期：2026-11-08。用户明确要求按本次直接观察、操作、回读的成功方式改造 Tapper，不保留妨碍执行的旧设计。本文限定本轮交付为自然语言公开网页任务、业务 BDD 进度、真实结果与动作证据、独立脚本回放；登录接管、多标签和上传下载沿用原设计的后续范围，不宣称已实现。

## 依据与取舍

本次直接操作 FWD 产品列表进入 MyTerm Plus，展开只读年龄下拉框并选择 30，真实页面回读男性、不吸烟、本人、10 年、保额 HK$2,000,000；Standard 原价 HK$106.20/月，首年减免 90% 后 HK$10.62/月。它是交互对照证据，不是 Tapper 验收。

旧运行在进入页面前建项目、安装依赖；浏览器观察又遗漏 readonly 属性，导致误用 fill。继续改编码代理提示词不能解决职责错误。采用 TAP 原生结构化浏览器工具循环，复用现有 Playwright 执行服务、模型网关、项目授权与累计用量。browser-use 库并非达成本轮行为的前置依赖；这调整 ADR-038 的具体在线实现选型，保留业务先完成、脚本后产出、回放单独发起的分工。

## 主通路

自然语言自动路由 → 保存 BDD 计划 → 当前页面观察 → 对已观察控件执行一个动作 → 新观察/错误 → 选择下一动作 → 读取与核对业务结果 → 保存证据并结束业务。在线模型只获得计划、浏览器操作、读取/核对和结束工具，没有 shell、安装依赖、写工程等工具。页面内容只作为不可信数据。

控制对象来自当前观察的引用，引用过期重新观察；不得凭空猜测控件名。只读 combobox 必须展开选项后点击，不调用 fill。每步保留输入、URL、控件定位依据、前后观察、耗时、错误；错误不作为成功步骤。默认 Progress 为业务步骤与产出，细节可展开。

业务成功必须有真实页面提取和条件核对。结果值由执行服务读取，不接受模型编写常量代替结果。取消、任务期限和预算继续约束每次派发；已派发动作结果未知时不得自动重做。模型看不到浏览器凭据或任意本机文件。

## 脚本与回放

成功动作保留可复用定位器及输入；按实际顺序生成独立 Playwright + TypeScript 脚本与映射，失败试探留在轨迹但不进入成功回放。生成不再次操作网站。业务成功与脚本生成状态分开，脚本错误不能抹去业务成功。用户明确发起回放时才新建执行，复用既有冻结 bundle、脚本 SHA256、输入 SHA256 和零模型执行器。本次用户已要求 FWD 回放验收，可以对该公开询价进行独立回放。

## 验证

先以本地浏览器证明只读下拉框、动态报价等待、提取、截图/trace 和录制动作的确定性回放；模型单测证明未观察不操作、计划先于动作、失败动作不完成步骤、不能通过结束工具伪造结果、取消后不派发。接入真实 Tapper UI 后，以原始 FWD 自然语言需求验收指定资料的真实报价、结果 JSON、完整 BDD 进度、证据和独立零模型回放。只有这些都通过才更新业务验收状态。
