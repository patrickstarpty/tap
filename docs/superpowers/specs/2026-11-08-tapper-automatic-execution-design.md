# Tapper 自动执行与任务详情

## 用户确认的目标

2026-11-08 用户明确要求对标 Manus 的自然语言入口：无需勾选 Browser run，无需 @Agent，系统理解需求并选择执行能力；手动指定 Agent 保留为可选覆盖。用户提供 Codex 截图，要求进度以产出、参与 Agent、来源组织，不能用服务器事件流充当产品进度。调试层必须能展开每个真实动作的输入、结果、耗时和失败原因。

## 实现边界

沿用原生工作流的已计费模型路由与冻结 Agent 目录，新增 browser 路由并接入现有隔离编码/执行器，不在前端用业务关键词假装理解意图。路由选择、网页起点和输入冻结为持久化事件，后续查询、重放使用同一记录；保留原费用、调用、取消、授权和 URL 隔离限制。URL 缺失或低置信度时提出具体问题，不编造目标地址；普通问答不自动开浏览器。已有显式 browser API 保持兼容。

默认输入区只显示自然语言输入和可选上下文；浏览器细项收进可选的 Execution options，默认 Automatic；已有阻塞任务可补充输入，不作为首次发送的前置配置。自动执行由服务配置决定，用户不负责配置工程边界。

任务详情以产出、Agent、来源为主体；Agent 列表按 Active / Done 分组，保留每项真实成功、失败、取消及未知状态，点击可追溯。没有实际子 Agent 不虚构实例；浏览器根任务可以展示真实执行动作。隐藏运行 ID 和底层事件于诊断详情。进展从持久化事实派生，无估算百分比。

浏览器检查器返回有界的交互控件、实际选择值与可用定位器；错误不抹掉已加载 DOM。操作开始、完成、失败记录到同一任务，含动作 ID、顺序、类型、目标、定位器、耗时、脱敏结果摘要及真实错误。填入值默认隐藏；URL 去除凭据和敏感查询；所有页面自由文本须经过原有服务端脱敏，脱敏失败时不公开。模型请求的元信息可诊断，但不公开密钥和原始模型请求体。截图/trace 只在真实产生时链接，缺失时明确说明。

## 验收

- 普通问答留在原生路径；浏览器需求无勾选和 Agent 选择进入编码执行；手动选择仍尊重。
- 路由及模型调用共享同一预算；禁用能力、URL 缺失、低置信度、取消、重复请求均有明确行为。
- 默认侧栏无重复 Activity recorded，无长目标全文和运行 ID；产出、Agent、来源可访问。
- 动作错误可展开查看定位器、URL、结果摘要、耗时及错误；敏感输入和密钥不泄露。
- FWD 合成资料和边界沿用既有设计 §11.1。真实报价、原脚本、截图、trace、零模型重放全部通过后才验收。

## BDD 计划与执行事实

收到执行需求后，先由模型拆成 Given / When / Then / And 业务步骤，并持久化 `browser.plan_created`；未保存计划或动作未引用计划 step id 时，服务端拒绝执行。用户无需先写 BDD。计划可因观察修订，必须说明原因且不能改写已执行步骤。生成脚本使用同名 `test.step`，Then 必须断言实际结果；浏览器观察成功只显示已观察，不能冒充执行验证通过。计划显示在聊天及任务详情中，动作起止事件实时关联对应步骤。失败详情含页面、定位器、输入隐藏标记、结果、耗时及错误；底层事件置于 Run details。

外层按用户提供的 Codex 示例采用 Outputs / Subagents / Sources；子任务展开 Active / Done 并可进入详情。对照 [Codex 开发者界面](https://learn.chatgpt.com/docs/developers)、[Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents) 与 [App Server 计划及动作事件](https://learn.chatgpt.com/docs/app-server)。BDD 是 Tapper 的业务计划，不声称 Codex 使用 BDD。

页面观察复用锁定 Playwright 1.62.1 的 `page.ariaSnapshot({mode: 'ai'})`，这是官方 CLI 同样使用的快照接口；动作优先使用最近快照的 完整 `aria-ref`（例如 `aria-ref=f1e61`），页面变化后重新观察，可局部快照。冻结重放脚本采用观察到的 role/label/CSS 定位，禁止使用会话临时 refs。参考 [官方 CLI 快照](https://playwright.dev/agent-cli/snapshots)。不另装 browser-use Agent，不扩展网络或执行权限。必须用真实页面检验效果，不能由库选择直接推导验收成功。
