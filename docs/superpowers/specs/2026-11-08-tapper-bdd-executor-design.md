# Tapper BDD 合约执行器

2026-11-08 用户已同意本次架构修正。本文覆盖公开网页任务；保留现有自然语言入口、browser-use DOM/Agent、Browser API 会话、预算账本、录像和冻结回放。登录、人工接管、多标签、上传下载不增加范围。旧实跑和旧测试不能转记为新架构验收。

## 决策与边界

继续让模型自主选择业务步骤会再次空转；把所有任务预写成站点脚本又失去通用定位能力。采用已同意的分工：需求和计划先验收，TAP 执行器控制顺序与权限，browser-use 只寻找当前步骤的页面目标，TAP 根据真实回执推进。常见动作直接编译为回放；无法转换时保留业务成功，明确脚本失败，不交给另一个模型重新设计流程。

## 合约

计划包含需求清单及顺序步骤。需求使用唯一 ID、input/result 分类、原需求中的原文依据和期望；每个 input 必须有 When 操作及 Then 验证，每个 result 必须有 Then 提取。Given 确认起始页面或前置事实，When 导航、点击、填写或选择，Then 只读断言。And 必须显式声明继承的阶段，存储时转为具体阶段。相同字段的 When 和 Then 合法；相同需求的同类重复步骤、缺失验证、引用不存在、空断言、模型要求的导出/脚本动作不合法。

冻结字段包括步骤 ID、操作类型、目标文本别名和可选局部上下文、输入值、读取属性、比较方式、期望值及输出名。定位器不在规划时猜测。执行期模型只能提供当前步骤 ID、计划摘要和当前观察的元素 index 或只读断言的 selector；不能提供新输入、断言、输出或下一步 ID。规划器与一次独立计划审查经同一计费网关；结构检查失败或审查发现遗漏即停止，不能一边执行一边修订计划。语义审查不是数学完备性证明，不宣称任意自然语言都能可靠理解。

## 执行与证据

执行器只持有一个当前步骤；确认回执后推进，失败留在原步。Given 导航必须有 completed 回执及目标 URL 观察；When 点击/填写/选择按对应操作的回执完成，不强制重复一次模型验证；Then 执行冻结断言并保存 Browser API 实际读出的值。Then 禁止写操作。SDK done 不能覆盖未完成步骤，也不能提交结果常量。

所有写动作走 Browser API。执行服务在定位器上读取真实标签、文本、ID/name 及受限局部上下文，核对冻结目标后才操作。文本匹配采用规范化词边界，避免 Male 匹配 Female；需要局部范围时同样校验。目标歧义、readonly 填写、跨步骤、旧计划摘要均在写入前拒绝。页面语义无法可靠对应时阻塞，不用猜测别名自动放宽。Browser-use 的原生任意导航、键盘、坐标、JS、文件等工具不作为旁路暴露。

只读下拉框的选择允许先展开，再选择冻结值；展开是当前步骤的子动作，不推进业务步骤。最终选择需要真实字段值/选中态确认。所有子动作和失败保留在轨迹，只有确认成功的动作进入回放记录。每条记录含步骤 ID、动作 ID、计划摘要、定位器和冻结值/断言；不能把未知回执视为成功。

## 有界失败

格式错误最多纠正一次；同一失败动作第三次停止。未知动作回执立即停止，不自动重做。等待使用页面条件和已有有限超时，不增加固定睡眠。每个步骤允许有限定位/展开尝试；重复观察不重置额度，推进下一业务步骤才重置。取消和总预算继续在每次派发前生效。规划和审查最多各一次，格式修复计费；执行留有独立调用上限，确定性编译和普通回放不调用模型。

## 回放与验收

复用确定性编译器，新增明确支持的操作和断言；未知动作必须拒绝，不能静默遗漏。脚本保留动作次序、BDD 来源、目标约束和冻结断言，结果重新从页面读取。脚本生成不访问站点，不执行第二次业务；每次用户已授权的回放新建执行和录像，零模型调用。

先完成合同和本地浏览器门禁：合法 When/Then、遗漏/重复需求、越序与旧摘要、Then 写入、错目标、篡改值/断言、readonly 选择、未知回执、三次失败、观察空转、取消、生成不调用模型、回放真实执行。核心回归和静态检查通过后才恢复 FWD/AIA。两例均须验证指定输入、非零真实报价、原操作录像、确定性脚本、独立回放录像与零模型账本；任何一个缺失均未验收。
