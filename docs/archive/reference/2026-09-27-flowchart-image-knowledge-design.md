# 流程图图片知识设计

日期：2026-09-27。状态：实施设计。承接 [RFC-011 AI 与知识专题](2026-09-22-rfc-011-ai-knowledge-design.md#复杂文件解析与检索)。本设计只处理单张 PNG/JPEG 流程图上传后的可信问答，不声明扫描 PDF、Office 绘图或一般图片理解已经交付。

## 用户结果与边界

用户在 Library 上传流程图图片，看到解析的节点、箭头、条件、泳道与无法确认的连接；核对后独立复核并发布。发布的内容成为 Tapper 可选择的 Source。Tapper 能回答流程的步骤、分支、回路和参与者，给出指向该图片及区域的引用；未确认的关系不能被回答成确定事实。图片原件、结构化语义和模型产物都有不可变 Revision 身份。撤回或删除之后不能再进入新问题检索。

## 数据和处理路径

1. 上传沿用 Source/Document reservation、25 MiB 界限与内容寻址原件。隔离解析器验证 PNG/JPEG 签名、解码、像素边界与单帧，在隔离进程内清除元数据并为视觉模型缩放；拒绝截断、伪装、超限及带旋转 EXIF 的图片，以保持引用坐标与原图一致。图片保留原件，不把 EXIF、嵌入文本或文件名当作知识。
2. 视觉分析步骤通过项目授权的 ModelGateway 路由，把隔离处理后的图片发送到视觉模型。模型以封闭 JSON 输出节点、连线、方向、分支条件、泳道、区域坐标和疑点；图片请求实际携带 Schema；`TAPPER_VISION_TIMEOUT_SECONDS` 默认 60 秒（不超过 60 秒），独立于文本模型的 15 秒超时；强制声明 `coordinate_space: normalized_1000`，系统验证后直接换算到原图像素。服务端验证端点存在、坐标在图内、字段与大小限制，不能依靠模型置信度自行发布。
3. 将每个节点、关系和疑点写成可核对的 Inventory 项，记录模型配置、原件摘要与位置。审核可接受或排除模型提议，也可更正节点名称、泳道、区域坐标与连线端点、方向、条件及确定性，支持新增/删除遗漏或多余的节点与连线。更正保留原件，按前一修订与完整图结构摘要生成新的解析版本和不可变 Source Revision，重新分块、嵌入与索引；旧审核结果失效，修订历史保留操作者与新修订，独立复核不得由更正者完成。已发布修订不能原地更正。由已确认结构生成带节点 ID、方向、条件及泳道的检索文本块，使用现有文字 Embedding 与 `doc` 索引；节点和连线文字块均带图片区域锚点。规范化产物同时保存可读回的节点与连线结构。
4. 本次“向量化”指流程语义的文字向量化，用于文字问题检索和问答。原图只作为受权审核原件保存；尚未建立图像 Embedding 或独立图像向量索引。若后续需要以图搜图，应使用独立模型与索引空间，并受同一 Source Revision、发布与撤回约束，不得与文字向量混用。
5. Review 对节点、连线和条件逐项显示原图区域与解析结果。悬空、交叉、无方向或低清晰度连接默认待确认；严格模式阻断，普通模式仅允许明确排除该项后发布其余范围。发布前检查确认结果、文字/图像投影和引用位置属于同一 Revision。会话仍使用现有授权、冻结来源、证据快照、引用核验和撤回规则。
6. 问答检测已批准图片证据后，使用同一权限与批准清单精确读取所选修订的已发布连线，避免语义检索 top-k 截断关系。当前回答契约最多 20 条连线，超限显式拒绝，不能把截断图称为完整流程。路径遍历有界，分开列出分支；一次路径不重复使用同一条边，允许回到决策节点后更换结果，支持失败→重试→成功。同一结论引用的连线必须能同处一条已枚举路径，否则拒答；这不是自然语言语义的完备证明，也不求解数值/任意文本条件。
7. 图外高风险阈值、批准权限和时限从同一已选已发布资料范围补检索，证据上限仍为 20，剩余额度不足时不能补出不存在的制度依据。没有明确文本支持就说明未知。完整已批准连线集合不等于原图全部关系：被排除、未确认或模型遗漏的关系仍不在结论范围。

## 失败与验证

不支持的格式、损坏图片、像素超限、视觉模型不可用、结构输出无效和待确认关系应各有安全错误或显式审核状态。不得把原件或模型输出写入日志；发送给视觉模型的是去掉图片元数据、必要时缩小到请求上限的像素图。测试覆盖签名/尺寸拒绝、方向与条件保真、歧义阻断、跨项目隔离、重复上传/重试、重启恢复、索引读回、撤回/删除，以及上传→复核→发布→多轮问答与引用。合成样本证明链路；真实流程图样本和真实模型的端点/方向/条件准确率需另行测量，不能由模拟测试替代。
